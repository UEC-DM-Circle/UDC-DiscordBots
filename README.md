# UDC-DiscordBots

UDCで使うDiscordBotのリポジトリです。

.envファイルは管理者が所有しています。

## 管理者

- Gitudon

## 使用済みのコマンドプリフェックス

- `~`：Announce
- `-`：Card-Recruitment
- `_`：Data-Mining
- `+`：Information
- `?`：Matiching
- `!`：PDFmaker
- `*`：Twitter
